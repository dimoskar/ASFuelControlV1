GetInvoiceListData(int pageInt, string TokenToUse, string IssuerVat, string InvMyDataType, string DateFrom, string 
DateTo, int? brachNum) 
Με την μέθοδο “GetInvoiceListData” μπορούμε να λάβουμε από την υπηρεσία όλα τα παραστατικά που έχουν εκδοθεί 
μέσα από αυτή. Κάθε κλήση μας δίνει και μια δεκάδα παραστατικών. 
Στην εντολή αυτή συμπληρώνοντας το πεδίο branchNum (μορφής integer) μας φέρνει τα σχετικά αποτελέσματα για το 
συγκεκριμένο branch (Υποκατάστημα). 
Ακόμα σ την εντολή αυτή, συμπληρώνοντας το πεδίο InvMyDataType μπορούμε να επιλέξουμε τον τύπο – κωδικό 
παραστατικού MyData το οποίο θέλουμε να λάβουμε σε λίστα τα αποτελέσματα από τα εκδοθέντα παραστατικά. Τέλος 
συμπληρώνοντας τα πεδία DateFrom και DateTo ορίζουμε το ημερολογιακό διάστημα για το οποίο θέλουμε να λάβουμε 
την λίστα των παραστατικών. Η μορφή των ημερομηνιακών πεδίων αναζήτησης θα πρέπει να είναι "dd-MM-yyyy" και 
βέβαια το πεδίο DateFrom να περιέχει ημερομηνία μικρότερη ή ίση από το πεδίο DateTo. 
Στην πρώτη κλήση που θα κάνουμε εκτός της δεκάδας των παραστατικών που θα μας έρθει σε λίστα κόμβου data, θα 
λάβουμε και αντικείμενο με την ονομασία meta όπου φέρει τις ακόλουθες πληροφορίες: 
• current_page // Αριθμός σελίδας αποτελέσματος (SUCCESS 200) 
• last_page // Αριθμός τελευταίας σελίδας αποτελεσμάτων 
• from // Παραστατικό Από 
• to // Παραστατικό Έως 
• per_page // Παραστατικά ανά σελίδα 
• total // Συνολικά Παραστατικά 
 
Κάνοντας χρήση των δεδομένων που μας δίνονται στο αντικείμενο αυτό, μπορούμε εκτελώντας την συγκεκριμένη εντολή 
να λάβουμε όλα τα παραστατικά απλά αλλάζοντας (αυξάνοντας) κάθε φορά το πεδίο pageInt. Στο επόμενο πεδίο όπως 
και για τις υπόλοιπες εντολές θα πρέπει να δώσουμε σε μορφή string το token επικοινωνίας. Τέλος λαμβάνουμε σαν 
object τα ακόλουθα πεδία απάντησης: 
• int StatusCode // Ο κωδικός του αποτελέσματος επικοινωνίας 
• String ProcErrorReply // Κείμενο με την περιγραφή του σφάλματος στην περίπτωση ανεπιτυχούς διαδικασίας 
• Object ProcLstInvoiceReply // Αντικείμενο με συμπληρωμένα τα πεδία απάντησης από την υπηρεσία στην περίπτωση 
επιτυχούς διαδικασίας 
• Object ProcHeaderCollection // Αντικείμενο με τα headers από την διαδικασία επικοινωνίας 
• String ProcEndpoint // Κείμενο με το URL το οποίο έγινε η επικοινωνία 
• String ProcDuration // ο χρόνος διάρκειας της επικοινωνίας

Με την μέθοδο “ImageFromB64Str” δίνοντας σε μορφή string Base64 encoded, σε μορφή int το επιθυμητό πλάτος και

Μορφή Δεδομένων: 
Από τα δεδομένα που θα πρέπει να συμπληρωθούν στην δημιουργία του Object παραστατικών, το πεδίο “ext_system_id” 
συμπληρώνεται από το εμπορικό και αφορά το αναγνωριστικό που δίνεται από το ERP έτσι ώστε να υπάρχει πάντα ένας 
κοινός παρονομαστής αναφοράς μεταξύ αυτού και της υπηρεσίας iTimologia. 
Για τα παραστατικά χονδρικής, στην λίστα “notify”, προσθέτουμε τους επιθυμητούς παραλήπτες του παραστατικού. 
Όπου “channel” βάζουμε το κείμενο “mail” και όπου “receiver_id” βάζουμε την διεύθυνση email του παραλήπτη.  
Όλα τα υπόλοιπα πεδία του Object που φέρει την δομή των παραστατικών είναι ακριβώς τα ίδια με τα πεδία που 
περιγράφονται στο MyData. Η ονοματολογία των πεδίων είναι σε μορφή Snake case σε αντίθεση με το MyData που κάνει 
χρήση μορφής Camel case. Αν γίνει χρήση είτε του DLL είτε της κλάσης C#, ακόμα και σε μορφή Camel case να δοθούν τα 
εισερχόμενα δεδομένα αυτά μετατρέπονται αυτόματα και η διαδικασία συνεχίζει. 
 
Για τις εντολές που περιλαμβάνεται  το Object ProcHeaderCollection περιέχονται οι παρακάτω πληροφορίες: 
• x-subscription-api-limit: int //Όριο κλήσεων API πακέτου 24ώρου 
• x-subscription-invoice-limit: int //Αρχικό σύνολο πόντων πακέτου 
• x-subscription-api-remaining: int //Υπολοιπόμενο χρήσης κλήσεων API 24ώρου 
• x-subscription-invoice-remaining: int //Υπολοιπόμενο σύνολο πόντων πακέτου 
• x-ratelimit-limit: int //Όριο χρήσης κλήσεων API ανά λεπτό 
• x-ratelimit-remaining: int //Υπολοιπόμενο χρήσης κλήσεων API ανά λεπτό
